# 小白 Demo：做一个"按一下亮、再按一下灭"的 USB 小灯

**适合谁**：从没设计过电路的人。全程不用懂元件、数值和 KiCad，也不用自己写或编译程序。

**演示的是什么**：一句话的想法，变成一块可以直接下单生产的电路板。中间每一步都有一个可以看得见的结果；对不对由 KiCad 和仿真器判定，不由 AI 自己说"没问题"。

**大约用时**：20–30 分钟。AI 画图和布线的时间每次不同。现场演示前建议完整跑一遍。

## 准备

1. 装好 dsh 和 dsh-kicad 插件（见仓库 [README](../../README.zh.md) 的"安装"），以及 KiCad 10。
2. 安装自动布线器：在 dsh 里输入 `/kicad-install freerouting`。它需要 Java 25，如果缺少，安装说明里会告诉你怎么装。
3. 准备一个**空文件夹**作为工作区，在 dsh 里打开它。
4. 把本目录下的 `firmware/button_light.hex` 复制进这个文件夹。这是事先准备好的程序：按钮接 PB3，灯接 PB4，按一下切换亮灭，并带 20 ms 消抖。AI 不会编写固件，工具也只读取工作区里的文件。
5. 侧边栏的 **跟随 agent**（Follow agent）保持开启：AI 新建或修改设计时，图纸会自动在右侧打开并实时更新。

## 演示步骤

每一步都分三部分写：**输入**（照着打）、**会看到**、**可以讲**。

### 0. 检查环境

- **输入**：`/kicad-doctor`
- **会看到**：一张"环境检查"卡片，KiCad、Python、Freerouting 都是绿色。
- **可以讲**：画图、检查、布线、导出都在本机由 KiCad 完成。AI 只负责操作工具，每一步对不对由 KiCad 判定。

### 1. 一句话说出想法

- **输入**：`/kicad-design 我想做一个 USB 供电的小灯：按一下按钮灯亮，再按一下就灭，以后还想改程序`
- **会看到**：
  - AI 先问 2–3 个选择题，例如怎么供电、以后怎么改程序。每题都标了"推荐"，点推荐的那个就行。
  - 然后它写出 `design-brief.md`：带编号的元件和连接清单，加一段用大白话写的"我替你做的假设"。
  - 最后问你 **照这个画 / 改一改**，点"照这个画"。
- **可以讲**：你不需要知道用什么芯片、什么电阻。AI 用一组验证过的电路模块，把想法补全成完整规格（USB-C 供电、3.3 V 稳压、ATtiny85 单片机、按钮、LED、编程接口），你只需要确认。

### 2. 看着原理图长出来

- **会看到**：
  - 右侧打开原理图，元件和连线一步步出现。
  - 图纸按功能分成带标题的框，例如 USB INPUT、PWR SUPPLY、MCU、ISP、UI。
  - 对话里每次修改都有一张卡片，上面写着 **自动 ERC · 通过**。
- **可以讲**：每改一次，KiCad 的电气规则检查（ERC）就跑一次，0 错误才算完成。

### 3. 检查芯片接得对不对

- **输入**：`帮我检查一下芯片接得对不对`
- **会看到**：ATtiny85 检查通过，0 错误。
- **可以讲**：这是针对单片机的专门检查，包括复位脚有没有上拉、电源有没有去耦电容、每个功能是不是接在能做这件事的引脚上。

### 4. 还没做出来，先"试玩"

- **输入**：`我准备好了一个程序 button_light.hex（按钮在 PB3、灯在 PB4）。帮我仿真：1 秒时按一下按钮，灯要亮，松开后保持亮；2 秒时再按一下，灯要灭；并把这个测试保存下来。`
- **会看到**：
  - **固件仿真 通过**，几条要求都打勾。
  - 时间线上灯在按下后约 20 ms 亮起：这是程序的消抖时间。
- **可以讲**：
  - 程序在模拟的芯片上真实运行，按钮和灯就是原理图里那两个元件。
  - 保存后，以后改了电路，输入 `/mcu-sim` 就能重跑这个测试，不经过 AI。
- **可选：失败演示**。
  - **输入**：`再加一条要求：按下后 10 ms 内灯就要亮`
  - **会看到**：这一条 **不通过**，理由是在要求的 10 ms 内灯一直是灭的（工具原文：never on in that window）。程序要消抖 20 ms 才点亮。
  - **可以讲**：结论来自仿真，不是 AI 说的。
- **如果灯一直不亮**：说明 AI 把按钮或灯接到了别的引脚。告诉它：`按钮改接 PB3，灯改接 PB4，然后重新仿真`。

### 5. 做成能下单的电路板

- **输入**：`把它做成可以在嘉立创下单的电路板`
- **会看到**一串卡片，同时右侧打开电路板：
  1. **从原理图更新 PCB**：一致性 0，即板子和原理图完全一致。
  2. **电路板修改**：按功能块自动摆放元件、两面铺 GND 铜，每张卡片都带 **自动 DRC** 结果。
  3. **自动布线**：**0 未布通**，DRC 0 错误。
  4. **生产文件**：**已导出**，可以 **下载 zip**，看 **3D 预览**。
- 也可以点右侧的 **3D**，拖动旋转看成品。
- **可以讲**：这个 zip 就是工厂要的全部文件（Gerber、钻孔、贴片坐标、BOM），直接上传到嘉立创就能下单。导出前 KiCad 还会把关：有 DRC 错误、没布通或和原理图不一致时，导出会被拒绝。

## 演示者验收（可选）

演示结束后，用一条命令确认结果，结论全部来自 KiCad：

```sh
python demo/button-light/check.py packages/kicad-bridge/sidecar/src <演示用的工作区文件夹>
```

**原理图部分**沿用小白评测的检查：

- USB-C 供电和 CC 下拉；
- 单片机和编程接口；
- 按钮接到单片机，灯经电阻由单片机驱动；
- ERC 0 错误，封装齐全，有设计说明，元件不重叠。

**电路板部分**是板级检查：

- 一致性 0、0 未布通、0 个 DRC 错误；
- 在嘉立创工艺范围内；
- 两层板，有 GND 铺铜；
- zip 里 Gerber、钻孔齐全，并且是最新导出的。

## 现场出问题时

- **AI 卡住或画歪了**：用仓库里画好的同一电路继续第 3–5 步：`packages/kicad-bridge/sidecar/tests/fixtures/usb_attiny_blocks/`。把它复制进工作区，再把 `button_light.hex` 放进同一个文件夹。
- **布线报缺少 Java 或 Freerouting**：按卡片里的安装说明装好，再说一遍第 5 步。
- **想节省现场时间**：提前把第 1–2 步做好，现场从第 3 步开始。

## 关于这个程序

程序源码在 `firmware/button_light.c`。重新编译需要 avr-gcc，运行 `firmware/build.sh` 即可。它跑在 ATtiny85 出厂默认的 1 MHz 时钟上。仓库的测试会在参考原理图上跑一遍第 4 步的仿真，保证这个 demo 一直能用。
